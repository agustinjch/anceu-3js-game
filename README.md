# Anceu 3JS Games

Two three.js games starring Pepe, the dog of Anceu (Ponte Caldelas, Galicia).

| Game | Folder | Run |
|---|---|---|
| **Pepe e as Pegadas de Anceu** | [`juego-pepe/`](juego-pepe) | `cd juego-pepe && npm install && npm run dev` |
| **Super Pepe Bros — A Faísca de Anceu**: a Mario-64-style 3D platformer | [`super-pepe-bros/`](super-pepe-bros) | `cd super-pepe-bros && npm install && npm run dev` |

**Asset generation**: [`meshy/`](meshy) — CLI around the Meshy API (text/image → 3D, rigging, animations). `node meshy/meshy.mjs help`

Inspired by Anceu village, Anceu Coliving and Rural Hackers.
